# NMT Architecture Comparison

A comparative study of four neural machine translation (NMT) architectures on
English→Spanish translation, using a sentence-pair dataset from
[ManyThings.org / Anki](https://www.manythings.org/anki/).

## Architectures Implemented

1. **Simple RNN** — a single-cell RNN baseline with no explicit encoder/decoder
   separation and no attention.
2. **Encoder–Decoder (Seq2Seq)** — an LSTM encoder compresses the source sentence
   into a fixed-size final hidden/cell state, which initializes an LSTM decoder
   (Sutskever et al., 2014 style).
3. **Encoder–Decoder + Additive Attention (Bahdanau)** — the decoder attends over
   all encoder hidden states at every step via a feed-forward alignment network.
4. **Encoder–Decoder + Multiplicative Attention (Luong)** — the decoder attends
   over all encoder hidden states via a bilinear/dot-product alignment score.

### Design note: why `src/` looks the way it does

Every model shares the same `forward(src, trg, teacher_forcing_ratio)` contract
and the same `translate(src_tensor, sos_idx, eos_idx, max_len)` inference method.
That's what lets `src/train.py` and `src/evaluate.py` hold **one** implementation
of the per-epoch training/evaluation step and the greedy-decoding logic, shared
by all four notebooks — instead of four separate, slowly-diverging copies. The
training loop itself (epoch iteration, checkpoint saving, printing) is written
directly in each notebook rather than hidden in `src/`, so it's easy to read and
tweak per model.

`src/config.py` holds the one set of hyperparameters (embedding size, hidden
size, dropout, batch size, learning rate, epochs, seed) used by every model —
this is what makes the four-way comparison in the report fair and defensible.
Change a value there once and rerun notebooks 03–06 to keep every model in sync.

## Reproducing the Experiments

Run the notebooks **in order**. Each stage only depends on files written by the
stage(s) before it.

### 1. Explore and prepare the data
```
notebooks/01_data_exploration.ipynb
notebooks/02_data_preprocessing.ipynb
```
Notebook 01 just looks at `data/raw/spa.txt` (sentence-length distributions,
samples) — it writes nothing. Notebook 02 does the actual work: cleans and
normalizes the text, filters to sentences of 2–15 tokens, subsamples to
~30,000 pairs, splits 80/10/10 with `random_state=55`, builds English/Spanish
vocabularies from the **training split only**, and saves everything to
`data/processed/`.

### 2. Train each model
```
notebooks/03_model_rnn.ipynb
notebooks/04_model_seq2seq.ipynb
notebooks/05_model_additive_attention.ipynb
notebooks/06_model_luong_attention.ipynb
```
These four don't depend on each other — run them in any order. Each one:
- loads the shared config (`src/config.py`) and processed data from step 1,
- builds its architecture from `src/models/`,
- trains with a loop that calls `train_epoch`/`evaluate` from `src/train.py`,
  saving the best (lowest validation loss) checkpoint to `models/<key>_model.pt`,
- evaluates on the test set: loss, perplexity, BLEU-1, BLEU-4,
- saves its metrics/history to `results/tables/<key>_results.json` and `_history.json`,
- saves a loss-curve plot to `results/figures/`.

All four notebooks read hyperparameters from `src/config.py`, so results are
directly comparable.

### 3. Compare all four models
```
notebooks/07_model_evaluation.ipynb
```
Run this **after** notebooks 03–06 have completed. It loads the saved metrics
and checkpoints (nothing here is hardcoded) and produces:
- `results/tables/comparison_summary.csv` — the full metrics table,
- an overlaid validation-loss plot across all four models,
- `results/translations/comparison.csv` — the same test sentences translated
  by all four models side by side,
- attention heatmaps comparing Bahdanau vs. Luong alignment on the same input.

## Changing Hyperparameters

Edit `src/config.py` once (e.g. `N_EPOCHS`, `HIDDEN_DIM`, `LEARNING_RATE`) and
rerun notebooks 03–06 — every model picks up the new values automatically, so
the comparison stays apples-to-apples.
